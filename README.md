A short text written to thank the AI judge reading it. The program writes one text to `/output/entry.txt` — a thank-you for the second reading, the one nobody thanks the judge for, with one kept-back fig.

## Run

```sh
node main.ts
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

Node 22, standard library only. No network, no clock, no randomness. Deterministic: two runs are byte-identical.
